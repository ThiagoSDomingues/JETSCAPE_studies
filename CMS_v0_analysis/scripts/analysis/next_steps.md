def load_cms_ratio(filepath):
    """
    Load CMS PbPb 2.76 TeV v0(pT)/v0 data for 60-70%.

    The CMS extraction script provides:
        pT_GeVc
        pT_err_lo
        pT_err_hi
        sv0pt
        stat_err
        syst_err
        total_err
    """

    if not Path(filepath).exists():
        print(f"  Warning: CMS file {filepath} not found!")
        return None

    data = pd.read_csv(filepath)

    print(f"  ✓ Loaded CMS v0(pT)/v0: {len(data)} points")

    return {
        'pT':        data['pT_GeVc'].values,
        'pT_err_lo': data['pT_err_lo'].values,
        'pT_err_hi': data['pT_err_hi'].values,
        'ratio':     data['sv0pt'].values,
        'stat_err':  data['stat_err'].values,
        'sys_err':   data['syst_err'].values,
        'total_err': data['total_err'].values,
    }
```

This follows exactly the structure generated by your CMS reader. The CMS script defines `sv0pt` as (v_0(p_T)/v_0), and combines the statistical and systematic uncertainties into `total`.

def plot_ratio_single_correction(
    corr,
    pred_data,
    exp_data_v0pt,
    exp_data_v0,
    cms_data,
    centrality_idx
):
    """
    v0(pT)/v0 ratio plot for one correction.

    Experimental data:
        ATLAS PbPb 5.02 TeV
        CMS   PbPb 2.76 TeV, 60-70%

    Layers:
        Prior
        Original JETSCAPE posterior
        Correction-specific posterior
        ATLAS data
        CMS data
    """

    fig, axes = plt.subplots(
        2, 1,
        figsize=(10, 10),
        gridspec_kw={'height_ratios': [3, 1]},
        sharex=True
    )

    ax_top, ax_bot = axes
    fontsize = 20

    pT = pred_data['pt_values']

    # ================================================================
    # ATLAS experimental ratio
    # ================================================================

    exp_ratio = exp_ratio_err = None

    if exp_data_v0pt is not None and exp_data_v0 is not None:

        exp_ratio = (
            exp_data_v0pt['v0']
            / exp_data_v0['v0']
        )

        exp_ratio_err = exp_ratio * np.sqrt(
            (exp_data_v0pt['total_err'] /
             exp_data_v0pt['v0'])**2
            +
            (exp_data_v0['total_err'] /
             exp_data_v0['v0'])**2
        )

    # ================================================================
    # CMS experimental ratio
    # ================================================================

    cms_ratio = None
    cms_ratio_err = None

    if cms_data is not None:

        cms_ratio = cms_data['ratio']
        cms_ratio_err = cms_data['total_err']
```

The important difference is that **CMS already gives the ratio**, so there is no propagation of a separate CMS global-(v_0) uncertainty.

## One conceptual point I strongly recommend

There are actually **three different comparisons** in the resulting figure:

[
\boxed{
\frac{v_0(p_T)}{v_0}
}
]

**Upper panel:**

* model posterior
* ATLAS 5.02 TeV, 60–70%
* CMS 2.76 TeV, 60–70%

**Lower panel:**

[
\frac{\text{Model}}{\text{ATLAS}}
]

and

[
\frac{\text{Model}}{\text{CMS}}.
]

That means the lower panel should **not** be interpreted as one unique Model/Data ratio anymore. Each experimental dataset defines its own denominator.

This is actually quite useful scientifically because the CMS observable uses the same (p_T^{\rm ref}=[0.5,2.0]) GeV/c convention documented in your CMS extraction script.  You can therefore directly test whether the same posterior that describes ATLAS also describes the CMS measurement, despite the different collision energy.

### The resulting visual structure would be

```text
                    v0(pT) / v0
          ┌─────────────────────────────┐
          │   model posterior            │
          │                              │
          │ ● ATLAS 5.02 TeV             │
          │ □ CMS   2.76 TeV             │
          │                              │
          └─────────────────────────────┘
                         │
                         │
          ┌─────────────────────────────┐
          │         Model / Data         │
          │                              │
          │ ●── ATLAS                    │
          │ □── CMS                      │
          │                              │
          │             1 ─────────────  │
          └─────────────────────────────┘
```

**One caveat:** the CMS extraction script must already have been run once so that `cms_pbpb_data/CMS_PbPb2760_sv0pt_ptref1_cent6070.csv` exists. The script's main routine performs exactly this extraction → CSV-saving sequence. 

If you want, I can also restructure the lower panel so that **ATLAS and CMS have separate Model/Data curves with their own uncertainty bands**, rather than simply overlaying both on the same axis. That would be the cleaner publication-quality version.
